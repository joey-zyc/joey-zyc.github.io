板块棋

v3 · 每回合两步：走棋子一步 / 走自家板块一步 / 各走一步

怎么操作

  • 点 自家棋子所在格 → 选中棋子（走一格，必须落到板块上）
  • 棋子压在自家板块上时，格子右下角有黄色 块 按钮 → 一键选中脚下那块板块
  • 或者按住 Shift 点自家板块 → 同样直接抓板块
  • 点其他自家板块 → 直接选中板块（只能移到相邻空格）
  • 绿框 = 可以走的位置，点它落子

规则

  • 棋子走到 对方家格 → 直接获胜
  • 棋子必须站在板块上，不能停在空白格
  • 板块上有棋子也能移动，棋子跟着板块一起走
  • 棋子落到对方普通板块格 → 对方可移动那块板块，把棋子带走
  • 连通规则在回合结束时才检查，中途可以随意拆；不过关则整回合作废退回重走
  • 棋子走到对方棋子所在格 → 吃掉对方，对方棋子回到自家家格
  • 选择"严格"时自家板块能动的很少，属于限制模式
棋盘比初始布局大很多，四周全是空白格，足够双方扩张。
